# Federico Caballero

ML engineer. I build machine learning systems that run in the real world, mostly on weather radar.

**[HailCast](https://github.com/fede-caballero/hailcast)** · Deep learning nowcasting of severe storms for Mendoza, Argentina. A ConvLSTM trained on a 2006–2014 radar archive, validated on 2025–2026 storms against a persistence baseline with bootstrap confidence intervals, deployed on a low-cost CPU server and used in production during the last hail season. Live at [hail-cast-mendoza.com](https://www.hail-cast-mendoza.com).

Before that I spent ten years reading weather radar to guide cloud-seeding flights at Aeronáutica Mendoza, where a wrong call has real consequences. That is where my habit of measuring every model against a baseline comes from. Today I also evaluate LLM outputs for a US-based AI lab and collaborate on radar research at UTN.

**Working on:** expanding HailCast's validation to 30–40 sequences, a residual-diffusion correction for severe-hail cores, and an LLM evaluation project.

**Stack:** Python · PyTorch · NumPy · xarray/NetCDF · FastAPI/Flask · Docker · Next.js · PostgreSQL/SQLite
